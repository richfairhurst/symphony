# Code of Conduct

Symphony aims to be a constructive, respectful technical project.

Contributors and maintainers must communicate professionally and must not
harass, discriminate against, or threaten others. Critique code and ideas,
not people. Unwelcome sexual attention, personal attacks, doxxing, and
deliberate disruption are not acceptable.

Maintainers may remove comments, close discussions, or restrict participation
when behavior violates this standard. Report conduct concerns privately to the
repository maintainers rather than opening a public issue.
